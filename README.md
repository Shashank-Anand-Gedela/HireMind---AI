# 🤖 HireMind – AI Interview Assistant

## 📌 About Project

HireMind is an AI-powered interview assistant designed to help students and job seekers prepare for interviews. It analyzes the content of a resume and generates meaningful interview questions based on the skills and experience mentioned.

This project was developed during my internship with IBM Edunet Foundation, where I explored AI, NLP, and real-world application development.

---

## 🚀 What this project does

This application performs the following functions:

* Accepts resume in PDF format from the user
* Extracts text using PyPDF2
* Processes the text using NLP techniques
* Uses AI to understand the content
* Generates interview questions based on resume
* Helps users practice and improve interview skills

---

## 🛠️ Technologies Used

The project uses the following technologies:

* Python → Core programming language
* Streamlit → Used to build interactive UI
* Gemini API → Used for AI-based question generation
* PyPDF2 → Used to extract text from PDF
* Scikit-learn → Used for processing and analysis

## ▶️ How to Run

Follow these steps to run the project:

1. Clone the repository
2. Install required Python libraries
3. Run the Streamlit application
4. Upload your resume
5. View generated interview questions
